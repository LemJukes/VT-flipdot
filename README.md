# VT-flipdot

A flip-dot display for [Verbatempus](https://verbatempus.com): a board of round dots, each lit or
dark, that spells out the date and time in words. Once a minute the new phrase is drawn as a dot
frame, and only the dots that differ from the board flip, in a sweep from left to right.

**Live:** https://lemjukes.github.io/VT-flipdot/

It is a static page. There is no build step, no dependency and no network request beyond the page's
own files.

## Parameters

| Parameter  | Values                                                        | Default            |
|------------|---------------------------------------------------------------|--------------------|
| `level`    | `verbose` `lengthy` `short` `terse`, any case                 | `verbose`          |
| `at`       | `HH:MM` (today) or `YYYY-MM-DDTHH:MM`, local time, 2010-2099  | the live clock     |
| `interval` | milliseconds, 250 or more                                     | on every minute    |
| `phrase`   | any text                                                      | the live clock     |

- `level` sets how wordy the phrase is, and the size of the board. An unknown value is `verbose`.
- `at` freezes the board at that time. With `interval` as well, it becomes a simulated clock that
  starts there and moves on one minute every `interval` milliseconds:
  `?at=2026-12-31T23:58&interval=2000` runs through midnight into the new year.
- `interval` alone re-reads the real time every N milliseconds instead of on each minute, as
  [VT-split-flap](https://github.com/LemJukes/VT-split-flap) does.
- `phrase` shows fixed text, upper-cased, with anything outside A-Z turned into a space.
  `?phrase=THE QUICK BROWN FOX JUMPS OVER THE LAZY DOG` shows all 26 letters.
- Invalid values are ignored. Lines that do not fit the board are dropped with a console warning.

The board is 97 dots wide (16 characters). Its height follows the level, sized so that no phrase
Core can produce at that level is cut off: 73, 49, 41 and 25 dots high at verbose, lengthy, short and
terse. A test checks that against every minute of every day from 2010 to 2099.

With "reduce motion" set in the operating system the board changes in a single frame. A page that was
hidden shows the current minute at once when it comes back, instead of replaying missed sweeps.

## Tests

```sh
npm test
```

This runs `node --test` (Node 22 or later) with no install step. The tests cover everything except the
drawing itself: the glyph table, wrapping, the raster, the update plan, the clock, the query
parameters, the static rules for `index.html`, and the corpus check above. They load the same scripts
`index.html` lists, in the same order.

## Phrasing

All the wording comes from [verbatempus](https://www.npmjs.com/package/verbatempus) **2.0.1**, vendored
unmodified as `vendor/verbatempus.iife.js` (sha256
`506df0316b05c9100b3915a8b46b9710e1aaaf0335b25380b60cbbb5fa0c395c`, the file in the npm tarball).
`.gitattributes` keeps it byte-exact on every platform, and a test checks the hash. This repository adds
no phrasing logic.

## Provenance

The code was written from this project's own specification. No existing flip-dot emulator, font file or
character-ROM table was consulted or reproduced. The 27 glyphs (A-Z and space, 5 by 7 dots) were drawn
for this project. The line-wrapping code is carried over from VT-split-flap, by the same author.

The code in this repository was generated by an AI model; all design decisions, and responsibility for
the code, rest with the developer.
